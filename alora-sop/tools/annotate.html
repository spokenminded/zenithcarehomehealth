Zenith Screenshot Annotator

Alora Office Operating Manual
Open a screenshot of live Alora (or press Ctrl+V to paste one).
Screenshots must show a test patient, or every patient name must be blacked out with the Redact tool.
How to use
  1. Open or paste a screenshot of one Alora screen. Capture only the window, at 100% zoom.
  2. Type the step id from screens-needed.csv (for example up-4).
  3. Use Redact on every real patient name, birth date, phone, address and ID number. Use Number for the red circles (they count 1, 2, 3 in order), Box around the item to click, Arrow from a circle to the item, and Label for a short word such as "Search".
  4. Click Save PNG. Put the file in alora-sop/src/screens/ with the name <step id>.png. Rebuild. The page then says FROM LIVE ALORA.
  5. Make sure the red numbers match the numbered list on the step page, in the same order.
Privacy: this tool runs only in your browser. Nothing is uploaded. A screenshot with real patient information must never be saved in the binder, the website or a chat.
